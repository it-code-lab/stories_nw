Build Coloring Manifest & Thumbnails


        
        

        

            • Each immediate subfolder of application/<source_folder> is treated as a category.

            • If a category has a pages/ folder, PNG/SVG files from there are used;
            otherwise images directly under the category folder are used.

            • If PNG and SVG both exist:
            
    
                
  • Thumbnail: generated from PNG → WEBP in thumbs
    • 
                
  • src in manifest: points to SVG URL
    • 
            

            • If only PNG exists: both src + thumb use PNG-based resources.

            • If only SVG exists: src uses SVG, thumb falls back to SVG URL.


            • Thumbnails are written to thumbs/ inside each category.

            • A manifest.json file is written to the root folder you specified.


            • After successful execution, delete png files from pages folder and place the above mentioned root folder
            under /coloring/static/v2/.


            • Place the manifest.json under /coloring/static/manifests/ as v2xx.json.

            • Update v2xx.json version in coloring\scripts.js and increment script?v= in index.html.
